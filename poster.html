משך פיתוח ותהליך

🔄 זרימת הודעות (MQTT → DB)

MQTT message
→ MqttDriver routes by topic
→ Entrypoint: JSON → Event
→ MessageBus.handle(event)
→ Handler persists via Repository
→ async Session (per message tx)

🍓 זרימת ראייה (Pi → DB)

Raspberry Pi Camera Module 3
→ Picamera2 captures frame
→ Roboflow Inference SDK
→ YOLOv8: Flower/Green/Red
→ paho-mqtt publishes stage
→ Backend updates lifecycle

🚿 בקרת שקיה (HTTP → MQTT)

POST /actuation
→ FastAPI router
→ ActuationService publishes cmd
→ MQTT command to ESP32-S2
→ ACK resolves Future
→ HTTP 200 response
