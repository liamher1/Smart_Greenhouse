# 🍓 Smart Strawberry Greenhouse (IoT + Edge AI)

An advanced, event-driven IoT greenhouse management system that combines Computer Vision (Edge AI) and adaptive control to optimize crop yield and fruit quality (Brix Optimization via Water Stress).

## 🚀 Overview
This project provides an end-to-end smart agricultural solution. Built on a highly scalable **Modular Monolith** architecture, it integrates field sensors (ESP32 via MicroPython), event-driven communication (MQTT), and a sophisticated asynchronous FastAPI backend. The system utilizes YOLO models for real-time ripeness detection and dynamically adjusts irrigation strategies (Data-Driven Automations) based on the fruit's life cycle to maximize sugar content in the final product.
